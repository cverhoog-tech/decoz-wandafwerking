# Decoz Wandafwerking

Premium testwebsite voor Decoz Wandafwerking.

## Structuur

- `index.html`
- `diensten.html`
- `portfolio.html`
- `werkwijze.html`
- `over.html`
- `contact.html`
- `style.css`
- `script.js`
- `assets/`

## Deploy via Vercel

1. Ga naar Vercel.
2. Kies **New Project**.
3. Selecteer deze GitHub-repository.
4. Framework preset: **Other** of **Static**.
5. Build command leeg laten.
6. Output directory leeg laten of `.` gebruiken.
7. Deploy.

De website gebruikt tijdelijke premium sfeerbeelden. Deze moeten later worden vervangen of aangevuld met echte projectfoto's van Decoz Wandafwerking.
